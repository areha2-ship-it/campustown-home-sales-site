# Median Home Sale Prices in College Towns

## What this site is for

This website compares median completed home sale prices across 18 college towns.

## Live site

[https://areha2-ship-it.github.io/campustown-home-sales-site/](https://areha2-ship-it.github.io/campustown-home-sales-site/)

## Data notes

The chart and table group completed sales by city and state and exclude prices below $1,000. Medians are rounded to the nearest dollar, with half dollars rounded up. To regenerate the chart and table from the original CSV, run `python3 scripts/update_median_prices.py` from the repository root.

ChatGPT/Codex, HTML, CSS, Python, GitHub, and GitHub Pages.
